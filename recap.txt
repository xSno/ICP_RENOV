ICP RENOV - CONTRACT MANAGEMENT APP - S4 RECAP

Migration / schema
- Review and readiness are fully derived from persisted Contract/Snapshot/Conditions/template metadata.
- No migration 5, review table, readiness table, ContractDocument table, number or revision was added. Latest schema version remains 4.

Review domain / service
- domain/review.py defines bounded ReviewState, exact ReviewBlockId values, localized issues, block results, four generation checks and separate completeness/readiness projections.
- services/review.py contains explicit V1 business validation. It reads current persisted Contract snapshots, ordered items, signatory, Conditions and governed template metadata; UI contains no review business rules or SQL.
- Review summaries format dates deterministically as DD/MM/YYYY and monetary values with a French decimal comma; canonical dates and Decimal calculations remain unchanged.
- Review never auto-fixes, auto-selects, normalizes or persists a duplicate review snapshot.

Snapshot and model behavior
- Client, Site and Equipment review summaries use only Contract snapshots/items. Later master edits or archives do not change or invalidate those summaries.
- Equipment summary is bounded to count plus observation count; no annex or master internal notes are reproduced.
- Selected model is defensively rechecked for existence, AVAILABLE status, Contract type and exact regime. Archived/TO_VALIDATE/incompatible versions remain referenced but make the model block and model capability unavailable.
- Conclusion mode remains required only by explicit selected-version metadata. An authorized early-performance question requires an explicit yes/no decision; stale unauthorized true state is reported without legal inference.

- generation_available requires complete Contract data plus all four technical checks; a pipeline problem never turns a business block into an error.

DEVELOPMENT VISUAL SMOKE ONLY
Run from the repository in one PowerShell session. This redirects machine/bootstrap and business state to a disposable TEMP folder and creates only synthetic master/template/Contract data through existing services:

$smokeRoot = Join-Path $env:TEMP 'ICP_RENOV_S4_VISUAL'
$env:LOCALAPPDATA = Join-Path $smokeRoot 'LocalAppData'
$env:ICP_S4_WORKSPACE = Join-Path $smokeRoot 'Workspace'
$smokeSource = @'
import os
from pathlib import Path
from icp_renov_contracts.bootstrap import build_application_context
from icp_renov_contracts.config import BootstrapConfig, MachineConfigStore
from icp_renov_contracts.domain import ClientDraft, ContractConditions, ControlledOption, EquipmentDraft, PaymentTermOption, SiteDraft, TemplateOptionCatalogs, TemplateVersionStatus
store = MachineConfigStore()
store.save(BootstrapConfig(Path(os.environ['ICP_S4_WORKSPACE'])))
ctx = build_application_context(config_store=store)
contract = ctx.contracts.create_draft()
client = ctx.master_data.create_client(ClientDraft(party_type='ORGANIZATION', organization_name='SYNTHÉTIQUE — CLIENT REVUE', address_line1='1 rue Test', postal_code='75000', city='Paris', proposed_contact_name='Nadia Roux', proposed_contact_role='Directrice'))
site = ctx.master_data.create_site(client.id, SiteDraft(label='SYNTHÉTIQUE — SITE', address_line1='1 rue Test', postal_code='75000', city='Paris'))
equipment = ctx.master_data.create_equipment(site.id, EquipmentDraft(equipment_type='Unité synthétique', location='Accueil'))
ctx.contracts.select_client(contract.id, client.id)
ctx.contracts.select_site(contract.id, site.id)
ctx.contracts.select_equipment(contract.id, equipment.id)
template = ctx.template_catalog.create_template('SYNTHÉTIQUE — MODÈLE REVUE')
version = ctx.template_catalog.create_version(template, 'review-visual-1', TemplateVersionStatus.AVAILABLE, ('CONSUMER',), catalogs=TemplateOptionCatalogs(('20',), (PaymentTermOption('DUE', 'À 30 jours', True, False),), (ControlledOption('TRANSFER', 'Virement'),), (ControlledOption('EMAIL', 'E-mail'),), ()))
ctx.contracts.change_regime(contract.id, 'CONSUMER')
ctx.contracts.select_template_version(contract.id, version.id)
ctx.contracts.save_conditions(contract.id, ContractConditions(visits_per_year=2, refrigerant_handling_mode='PARTNER', priority_breakdown=False, included_area='Paris', business_hours='8h–18h', travel_included=True, issue_date='2026-08-13', start_date='2026-09-01', initial_duration_mode='STANDARD', initial_duration_months=12, annual_ht='100', vat_rate='20', payment_terms_code='DUE', payment_due_days=30, payment_methods=('TRANSFER',), renewal_mode='NONE'))
print('Brouillon SYNTHÉTIQUE S4 créé :', contract.id)
'@
$smokeSourceBase64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($smokeSource))
python -X utf8 -c "import base64; exec(compile(base64.b64decode('$smokeSourceBase64'), '<s4-visual-smoke>', 'exec'))"
python -m icp_renov_contracts
